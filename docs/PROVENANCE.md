# Learning provenance and project naming

## Original learning work

The repository was created on **12 March 2025** as `nextwork-web-project-2025`. It originated in NextWork's guided Java/AWS learning work. The original page contained personal terminal-editing, source-control and EC2 connection messages. Those messages record experimentation; they do not establish a current hosted deployment or production service.

The source before this naming update is retained at commit [`8bf3b5f89ef462f813b3a3c60aee4fc80b52422e`](https://github.com/jyotheshkar/nextwork-web-project-2025/tree/8bf3b5f89ef462f813b3a3c60aee4fc80b52422e). Git history preserves the exact original files. This update neither recreates historical activity nor claims authorship of the guided curriculum.

## Professional project identity

The proposed repository name is **`Java-JSP-Web-Application-2025`**. The application and Maven project use **Java JSP Web Application**, with artifact coordinates `io.github.jyotheshkar:java-jsp-web-application:1.0-SNAPSHOT` and output `target/java-jsp-web-application.war`.

The name is deliberately specific to the retained implementation: a JSP page, servlet descriptor, Maven WAR build and optional CodeBuild instructions. No implemented REST API, database or provisioned cloud architecture is asserted.
